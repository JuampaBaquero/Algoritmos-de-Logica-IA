This project implements a expert system using the ***forward chaining*** algorithm. It takes the sentences ubicated at `/input/rules.json` and let you make queries about the data just like this:

*to implement*
```bash
uv run main.py q
```

> Running this you can check if the sentence q is true in your knowledge base
